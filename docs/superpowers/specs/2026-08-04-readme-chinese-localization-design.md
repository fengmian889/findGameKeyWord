# README 中文本地化设计

## 目标

将项目根目录的 `README.md` 完整翻译为简体中文，让中文使用者可以直接完成安装、配置、运行、排障和 GitHub Actions 部署，同时不改变项目的任何技术语义。

## 翻译范围

- 翻译标题、段落、列表、表格说明、警告和故障排查内容。
- 保持现有章节顺序与信息完整度，不删减安全限制、Google Trends 局限、基线规则、输出格式或实时测试说明。
- 不修改程序代码、工作流行为、配置默认值或数据格式。

## 保留原文的内容

- Shell 命令与代码块。
- 环境变量，如 `TRENDS_GEO`、`STATE_PATH`、`GITHUB_TOKEN`。
- 文件路径、URL、cron 表达式、JSON 字段和命令行参数。
- 产品、库、API 与协议名称，如 GitHub Actions、Google Trends、DataForSEO、Ahrefs、JSONL、CSV、HTTPS。

专业术语首次出现时可使用“中文（英文）”，后续使用自然、统一的中文表述。

## 验收标准

1. `README.md` 的说明文字全部为简体中文，不保留成段英文正文。
2. Markdown 标题、列表、表格、链接和代码块结构有效。
3. 所有命令、变量、路径、URL、阈值与原文一致。
4. 中文文档仍覆盖市场范围、本地安装、配置、基线、dry-run、GitHub 设置、输出、Trends 限制、未来付费数据源、故障排查与安全操作。
5. 文档修改不影响现有自动化测试。

## 验证方式

- 搜索遗留的成段英文正文并人工检查必要英文术语。
- 检查 Markdown 代码围栏数量与链接目标。
- 运行完整测试套件，确认只发生文档层修改。
